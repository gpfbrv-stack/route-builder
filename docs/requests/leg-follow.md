# 「道に沿う」を区間ごとの設定にする(ブランチ feature/editing-ux の続き)

## 目的
自転車用ルートビルダー(C:\Users\yuhei\route-builder、Vite + TypeScript + Leaflet、静的サイト)で、
「道に沿う」スイッチをOFFにすると既存ルート全体が直線になる。ユーザーにとって意味がないので、
走り方(legProfiles、直前のコミット 250fbf4 で実装済み)と同じく **区間ごとの設定** にし、
スイッチは「これから引く区間」にだけ効くようにする。

## 変更内容(1コミット相当)
1. 状態に区間ごとの「道に沿う」を持たせる(例: `legFollow: boolean[]`、長さ = 経由点数−1)。
   全体の `followRoad` は「これから引く区間の既定値」(スイッチの状態)として残す。
2. スイッチを切り替えても既存区間は再計算・再描画しない。ステータス(info): ON「これから引く区間を道に沿って計算します」/ OFF「これから引く区間を直線で引きます」。
3. 継承規則は走り方と同じ: 末尾追加=現在のスイッチ値、ルート線への挿入で分割された2区間=元の区間の値、経由点の移動=その区間の値のまま、経由点削除で結合される区間=前側の区間の値。
4. 既存の「この区間を現在の走り方で引き直す」「全区間を現在の走り方で引き直す」は、走り方と道に沿う(スイッチ値)の **両方** を現在値にする。
   文言は「この区間を現在の設定で引き直す」「全区間を現在の設定で引き直す」(PC編集バーは「全区間を引き直す」のまま)。Undo 1回で戻る。
5. 経由点リストの区間表示は、直線区間なら「直線」、道に沿う区間なら走り方名(例「ロード」)。
6. ルーティングのキャッシュキー・描画の区間キーは「区間の走り方+区間の道に沿う+区間座標」。直線区間はBRouterへ要求しない。
7. 保存・共有: localStorage と共有URLに `legFollow` を含める。共有URLは v3(v2/v1 は全区間を当時の `followRoad` 値として読み込む)。
   GPX読込は全区間を現在のスイッチ値にする(取り込みトラック保持中の既存挙動は維持)。
8. テスト: スイッチ切替で再要求・再描画が起きない、各継承規則、引き直し(1区間/全区間)とUndo、v1/v2/v3 の共有URL往復、直線区間で要求なし。
