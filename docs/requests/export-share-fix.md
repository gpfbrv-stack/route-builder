# 不具合修正: GPX/ガーミンが押せない・共有が反応しないように見える(ブランチ fix/export-share)

## 目的
リポジトリ C:\Users\yuhei\route-builder(Vite + TypeScript + Leaflet、GitHub Pages で公開中)。ユーザー報告2件を直す。

## 原因(レビュー側で公開版を実際に操作して確認、2026-10-11)
1. **GPX・ガーミンのボタンが無効(薄い)のまま**: `syncExport()` は `readyRevision === revision && placesRevision === revision` を条件にしており、
   OSM(Overpass)の峠・補給取得が終わるまで有効にならない。Overpass の各サーバーが遅い/失敗する状況では、25秒以上「補給・休憩を検索中…」のままでボタンが押せない。
2. **共有が反応しないように見える**: 共有は動いている(URL生成→クリップボード、失敗時は入力欄表示)が、結果の通知が状態表示の1行(優先度: 警告>処理中>情報)に
   info で出るため、Overpass の警告や「Googleの施設・地名を表示中」等に隠れて見えない。スマホでは共有ボタンが「…」メニュー内。

## 変更内容
1. **書き出しの有効条件**: 経路と標高の計算が完了(`readyRevision === revision` かつ 2点以上)した時点で GPX・ガーミンを有効にする。峠・補給の取得完了を待たない。
   押した時点で峠・補給(OSM/地理院)の取得が未完了なら、取得済みの分だけを含めて書き出し、トースト「峠・補給地点の一部は取得中のため含まれていません」を出す。
   ガーミンの先読み(preloadFit)は従来どおり経路完了時。
2. **トースト通知**: 状態表示とは別に、画面下部中央(PCは編集バーの上、スマホはボトムシートの上)に一時通知を出す部品を作る。
   - 3秒で消える。新しい通知が来たら置き換え。`role="status"` `aria-live="polite"`。DADSトークン(背景 --text、文字 白、角丸8px)。
   - ユーザー操作の結果(共有、GPX保存、ガーミン送信、ピン読込、経由点の追加など)の成功・失敗はトーストで出す(状態表示の既存メッセージはそのままでよい)。
3. **共有**:
   - スマホ相当(`matchMedia('(pointer: coarse)')` かつ `navigator.share` あり)では `navigator.share({ title: ルート名, url })` を呼ぶ。取り消し(AbortError)は何もしない。失敗時は下のコピー動作。
   - それ以外はクリップボードにコピーしてトースト「共有URLをコピーしました」。コピー失敗時は既存の入力欄表示+トースト「URLを表示しました。選択してコピーしてください」。
4. テスト: 峠・補給取得中でも経路完了で書き出しボタンが有効、取得中の書き出しで通知、トーストの表示・置換・自動消去、共有(share あり/なし/取消/失敗→コピー/コピー失敗)。
